Song library

Songs here can be reused in any Bank of any Set, without uploading them again. Uploading directly into a Bank slot below also adds it here automatically.

Supported formats: audio MP3, WAV — video MP4, MOV, MPEG, MPG (with embedded audio). Video: H.264, 1080p or less, ~8-12 Mbps recommended -- see LIBRARY.md for full encoding guidance.

Standby video

Loops silently on screen whenever nothing is playing. Pick any video already in the song library above -- to use a new file, upload it there first, then choose it here.
